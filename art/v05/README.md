# Иллюстрации 0.5

Сначала нарисованы герой и героиня в шести возрастах (6, 12, 20, 35, 52, 75): `refs.mjs`, id заданий в `refjobs.json`. Каждый следующий возраст рисовался по предыдущему, поэтому лицо одно и то же, но взрослеет. Чтобы модель не копировала референс слишком молодым, в промпте возраста прямо сказано, насколько человек старше («fifteen years older… clearly no longer a youth»).

Потом каждая из 122 сцен нарисована по портрету ближайшего возраста (`band` в `build-prompts.mjs`): описание сцены из `scenes.mjs` + уточнение возраста + общий стиль. Модель Higgsfield `gpt_image_2_5`, вариант `flare`, качество `medium`, 3:2, 0,5 кредита за кадр.

- `scene_prompts.json` — итоговые промпты и референс для каждой сцены (`node art/v05/build-prompts.mjs`).
- `jobs.json` — id задания для каждой сцены, `files.json` — имя готового файла на d8j0ntlcm91z4.cloudfront.net.
- Перерисованы после просмотра: F2-2 (больная не должна улыбаться), M6-1 (сбой генерации), M10-2, M12-2, F7-1, F7-2, F7-3, F11-3, F12-1 (герой улыбался в тяжёлый момент; в описание добавлено «not smiling» и нужная эмоция).
- 0.9: шесть новых первых сцен (M1-1 «Паром», M1-2 «Кораблик», M1-3 «Свист под окном», F1-1 «Семёрка», F1-2 «Рыжий», F1-3 «Шалаш») нарисованы в ChatGPT по тем же промптам из `scene_prompts.json` и портретам в 6 лет. Оригиналов на cloudfront у них нет: в `src/data/images.js` они помечены `LOCAL`, файлы `dist/img/v5-<ключ>.jpg` лежат в репозитории, `npm run art` их не трогает.
